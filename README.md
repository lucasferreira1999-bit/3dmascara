# 3dmascara

Loja Virtual Balaclava Mascara3D de Rosto Realista com Checkout PIX Integrado FreePay.

## 🚀 Tecnologias
- HTML5 / CSS3 / JavaScript Vanilla
- Node.js (Servidor nativo HTTP/HTTPS)
- Integração de Pagamento PIX instantâneo com Gateway FreePay Brasil
- Otimizado para Mobile e iOS (iPhone / Safari)

## 📦 Como Rodar Localmente
```bash
node server.js
```
Acesse em: `http://localhost:3000`
